# Beaconfall 音效與配樂來源

遊戲使用下列音檔的本機副本。音效剪輯片段、調整增益、轉為單聲道並合併為 `effects.mp3`。滑翔風聲節錄後在接點交疊。配樂調整響度及轉碼。所有作者保留其署名。CC0 素材依 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 提供。
