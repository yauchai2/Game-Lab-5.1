## 風格要點
1. 低解析度渲染後最近鄰放大（像素感），物件為低多邊形＋色塊陰影。
2. 色彩飽和但偏暖；陰影帶紫/藍；光柱與雲影是氣氛主角。
3. 水：多層藍＋等高線紋＋白色泡沫邊。
4. UI：奶油底、深咖啡字、像素字體、圓角像素框、極簡 HUD。

## UI 參考（`ui/`）— 2026-11-22 第二批
**兩種面板**：① 深咖啡底＋圓角、亮色字（道具/成就/魚類清單、拾獲提示、計數器）；② 奶油底＋咖啡字＋深咖啡粗邊（對話氣泡、選項選單）。
- 選中項：金黃外框＋左側白色箭頭；未解鎖項目暗淡、黑色剪影＋`???`。
- 強調字：橘色（名稱/數值）、淺藍（稀有前綴）、黃色（NEW 徽章）。
- 體力 = **金色羽毛**橫排（左下），拾物提示用小圖示＋計數（左上，深棕圓角小框）。
- 拾獲提示：頂部置中深棕橫幅「You found a ◎ Shell!」。
- 地圖標記：白色水滴形針＋按鍵圖示。望遠鏡：雙圓視野＋深灰藍邊框＋座標。
- 暫停：工具圈（圖示列＋說明）＋置中大寫選項文字。
- 平常畫面只留羽毛條，其餘都在需要時才出現。

## 城鎮參考（`town/`）— 2026-11-22 第三批
`t01`–`t14`：酒館與露天座、石板廣場、山牆木樑屋、條紋雨篷市集、花圃、水池小橋、雕像與旗幟大門、島嶼俯視佈局、像素草地與遺跡、手繪水面等（`t11_8bit_motion.mp4` 只在共用資料夾）。
套用到燈谷鎮的要點：
- **中心廣場**用不規則石板鋪成，向各建築放射小徑。
- **地標建築**（酒館：酒桶招牌、前廊吧檯、露天傘座）讓城鎮有主角。
- 房屋：石基＋木樑＋山牆瓦屋頂＋花箱＋煙囪炊煙，屋頂色彩分散。
- 大門：旗幟＋一對雕像＋花盆，框出「出發」方向（參考動森廣場構圖）。
- 柔和點綴：粉色櫻花樹、柏樹、花圃、水池、長椅、街燈；NPC 有職業與固定活動範圍。
