# 素材評估與工具檢查（2026-11-22）

## 1. MCP 檢查

| 項目 | 結果 |
|---|---|
| **Godot MCP** | 你的 Mac 上有原始碼資料夾 `~/Tools/godot-mcp`，但 **沒有接到 Claude**：Claude 桌面版回報的本機 MCP 伺服器清單是空的，這個雲端工作階段也沒有任何 godot 工具。 |
| **Mixamo MCP** | Mac 上有 `~/mcp-servers/unity-mcp-mixamo`（看資料夾名是 **Unity** 的 Mixamo MCP，不是 Godot 用的），同樣 **沒有接到 Claude**。 |
| Godot 本體 | 雲端環境沒有安裝；`~/Applications` 只看到 Hades、Stardew Valley 等遊戲，看不到 Godot（系統 `/Applications` 我沒有權限看）。 |

要啟用：把這兩個 MCP 加到 Claude 桌面版的設定（Settings → Developer → Edit Config，`claude_desktop_config.json` 的 `mcpServers`），或用 Claude Code 的 `claude mcp add`，重開後新的對話就能用。

## 2. temporary/ 交接區（本次看到的內容）

全部在 `temporary/assets/scenes/`，共 632 個檔案（137 fbx、69 obj、68 gltf、46 png…），沒有角色或動畫素材。
