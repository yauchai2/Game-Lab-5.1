# 技術規劃與實作

## 1. 引擎選擇（決策）

| 選項 | 結論 |
|---|---|
| Godot 4（透過 Godot MCP） | 本次無法使用：雲端環境沒有 Godot，Godot MCP 也沒有接到這個工作階段（見 `00_README.md` 的 MCP 檢查）。後續若接上，可照第 4 節移植。 |
| **Three.js 網頁版（採用）** | 雲端可直接建置、用 Playwright 自動截圖檢討；成品是一個 HTML 檔，任何瀏覽器都能玩，也能發布成連結。 |

## 2. 渲染管線（`src/render.js`）

```
場景 (MeshToonMaterial + 頂點色 + 陰影)
  └─► RenderTarget A：顏色 + DepthTexture   （解析度 = 視窗 / pixelScale，約 426×240）
  └─► RenderTarget B：法線（overrideMaterial = MeshNormalMaterial）
後處理全螢幕 shader：
  1. 描邊：4 鄰域線性深度差 > 閾值 → 近側像素乘暗並偏紫
  2. 摺痕：法線差大且深度接近 → 微亮（模擬筆觸高光）
  3. 雲影：深度重建世界座標 → fbm 雲遮罩 → 乘 0.8
  4. 光束：斜向帶狀噪聲（隨鏡頭微視差）加暖色
  5. 風線：稀疏白色細線
  6. 調色：區域 grade、飽和度 1.08、暗角、受傷紅邊、轉場淡出
  7. 4 階 Bayer 抖動（讓漸層保持像素感）
輸出到低解析 canvas → CSS `image-rendering: pixelated` 放大
```

重點設定：
- `ColorManagement.enabled = false`、輸出 Linear：讓 hex 色碼「所見即所得」，美術調色直接。
- 光源強度：three r155+ 的物理光照需要約 ×2.3（太陽）、×1.75（半球光）才接近舊版亮度。第一輪截圖過曝的教訓見 `05_決策與截圖檢討.md`。
- Toon 梯度：4 階 `[90,170,235,255]`，`NearestFilter`。
- 透明特效（預警圈、光柱、粒子）標記 `userData.noNormal`，不參與法線/描邊。

## 3. 世界生成（`src/world.js`）

- 0.5 單位網格（121×121），以「徑向距離 + fbm 扭曲」定義島嶼，第二層 fbm 決定高台（1.5 / 2.7 高），中心 6.5 單位內保持空地。
- 從中心洪水填充（flood fill）得到可走區域，貼著懸崖的格子再侵蝕一格避免穿模。
- 地形網格：頂點 xz 隨機抖動 → 非方格感的 low-poly；每個三角形依坡度/高度/離岸距離/路徑距離上色。
- 水：離岸距離場用 BFS 算出，存成 DataTexture，水面 shader 讀取。
- 道具：樹（松樹 3 層錐、圓樹 icosahedron 群）、岩石、灌木、草叢、花、蘑菇、石柱、木頭、路燈，全部以 InstancedMesh 繪製。
- 敵人尋路：每 0.25 秒從玩家位置算一次 BFS 流場（flow field），敵人沿梯度走。

## 4. 移植到 Godot 4 的對照（若之後接上 Godot MCP）

| Three.js | Godot 4 |
|---|---|
| 低解析 RenderTarget + CSS 放大 | SubViewport（低解析）+ TextureRect，`texture_filter = nearest` |
| MeshToonMaterial + 梯度 | ShaderMaterial：`diffuse = step` 或 ramp 貼圖，`light()` 函式 |
| 後處理描邊/雲影/光束 | 全螢幕 quad shader 讀 `DEPTH_TEXTURE`、`NORMAL_ROUGHNESS_TEXTURE` |
| 水面 shader + 距離場 | 同樣的 DataTexture → ImageTexture，或用深度差做泡沫 |
| InstancedMesh | MultiMeshInstance3D |
| 流場尋路 | 同演算法；或 NavigationServer3D |
| 角色（程式拼的幾何體） | 可換成 Mixamo 動畫角色（需 Mixamo MCP / 手動匯入 FBX） |

## 5. 檔案結構

```
lantern-vale/
  src/index.html   UI、樣式、HUD
  src/main.js      進入點與主迴圈
  src/render.js    低解析渲染 + 後處理
  src/world.js     島嶼生成、地形、水、道具、流場
  src/models.js    角色/敵人/拱門的程序模型
  src/game.js      玩家、技能、敵人 AI、Boss、掉落、房間流程
  src/loot.js      裝備、詞綴、傳奇、天賦
  src/ui.js        HUD、提示、選單
  build.mjs        esbuild 打包成單一 HTML（dist/index.html）
  bot.cjs / showcase.cjs / shot.cjs   自動試玩與截圖
```
建置：`npm i three@0.170.0 esbuild@0.24.0 && node build.mjs`，打開 `dist/index.html` 即可玩。
