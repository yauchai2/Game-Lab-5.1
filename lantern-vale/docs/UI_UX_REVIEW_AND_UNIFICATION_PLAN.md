# 《燈谷行 Lantern Vale》UI/UX 全面健檢與視覺風格統一規範

> **審計日期**：2026-11-24  
> **審計基準**：實機截圖 `auto-20261124-011419`（涵蓋標題畫面、背包、技能拼圖、怪物靈魂、異界設計台、鐵匠鋪、三層星圖、戰鬥 HUD、提燈巡遊與除錯列）  
> **文件性質**：永久 UI/UX 設計系統（Design System）與重構路線圖

## 精簡預設與操作層級

預設 HUD 保留目前區域、任務、方向、目標生命、玩家資源、已裝備技能及藥瓶。大絕就緒和巡遊啟用時才顯示對應快捷動作。詳情仍能由原本的功能入口進入。

| 介面 | 預設可見 | 需要時開啟 |
| --- | --- | --- |
| 冒險 HUD | 區域名、任務目標、資源和當前戰鬥提示 | 旅程狀態與世界動態。展開看戰力、金幣、星砂、連線人數、時段、潮汐、世界王、奇遇及同行隊伍 |
| 技能列 | 已裝備的技能、藥瓶。大絕充滿或巡遊中時顯示專用快捷動作 | 背包、拼圖、坐騎、回城與巡遊從冒險選單操作。既有鍵盤快捷鍵仍可使用 |
| 遊戲選單 | 開啟時顯示冒險類，分類列顯示目前所在 | 隊伍類放邀請、通訊、名單與分流。系統類放設定、音效、百科、更新與除錯 |
| 選角與存檔 | 職業名稱、摘要、暱稱、外觀和出發 | 展開看起始技能、填入小隊代碼，或在帳號的存檔管理區備份及刪除目前角色 |
| 裝備、拼圖、地圖 | 物品操作、拼盤與區域路線。彈窗保留右上關閉鍵 | 詳細屬性、天賦和地圖圖例按需展開 |

手機保留至少 44 CSS px 的常用操作目標。移動與戰鬥各自固定在底部一側，翻滾、跳躍和普攻在同一列，技能增減時上方列依內容增減。世界動態和貨幣從「任務」按鈕進入。

## 手機與窄視窗

手機保留木框、羊皮紙與暖金焦點。觸控戰鬥由左下搖桿和右下動作鍵構成，主要按鈕至少 44 CSS px。移動可以和普攻或跳躍同時操作，長按跳躍可在下降時滑翔。攻擊及技能優先瞄準附近敵人，沒有目標時朝角色面向施放。觸控取消、切到背景或進入彈窗時放開持續輸入。

生命與法力放在左上，任務、潮汐與世界事件收在同一面板。背包、拼圖與地區地圖由選單進入。選角及換裝在直向使用下方可捲動的面板，橫向使用側欄。世界地圖保留圖像航線，窄畫面加上島嶼選單。視窗與控制列使用系統安全區，原有鍵盤與滑鼠操作繼續由遊戲主迴圈處理。

執行時色彩及字體以 `src/index.html` 的 Lantern Craft UI 變數為準，觸控維持同一套配色。介面文字透過 `src/i18n.js` 共用翻譯。Fusion Pixel 2026.11.10 的 `zh_tw` 與 `ja` 字型及 OFL 授權隨遊戲資源出貨。單檔 Artifact 建置內嵌同兩份字型。用字庫 cmap 檢查固定文案的中日文字、拉丁字母、數字及標點。 [Fusion Pixel 發行版本](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.11.10)

## 一、現況實機 UI/UX 總評與 6 大核心問題

目前遊戲的功能深度已經非常豐富（物理背包、6×6 電路拼圖、靈魂鑲嵌、異界設計台、三層星圖、餘燼潮汐、提燈巡遊），但由於各系統分階段疊加開發，**實機截圖中已出現明顯的「視覺風格分裂」與「資訊重疊」問題**：

### 問題 1：小字號繁體中文「點陣化斷筆」嚴重影響閱讀（最優先）
- **實機證據**：在 `05_ui_souls.png`（靈魂說明）、`06_ui_atlas.png`（異界詞綴卡片）與 `07_ui_forge.png`（鍛造說明）中，11–13px 的繁體中文出現筆劃黏連、斷筆與發糊現象，閱讀吃力。
- **根因**：低解析度點陣字體在 12px 以下無法承載繁體中文的高筆劃密度。
- **解法（雙字體分工原則）**：
  - **標題／按鈕／數字／徽章（≥16px）**：保留風格化像素／圓體粗字，維持 *A Short Hike* 手作感。
  - **說明正文／數值明細／吐司通知（12–14px）**：統一採用清晰無襯線黑體（`"PingFang TC", "Noto Sans TC", sans-serif`）搭配 `line-height: 1.55` 與高對比深棕墨色 `#35241c`，徹底根治小字糊掉的問題。

### 問題 2：全遊戲混用 4 套互不統一的 UI 視覺語言
- **實機證據**：
  1. **羊皮紙硬像素框**（標題、背包、拼圖、靈魂、異界、鐵匠鋪）— `#fff4d9` 奶油紙底＋直角粗黑框。
  2. **深棕半透明現代膠囊**（`#topbar`、`#tideHud`、`#toasts`）。
  3. **深紫霓虹科技感卡片**（`#autoHud` 提燈巡遊卡）— 直接擺在深棕 `#tideHud` 正下方，色相與圓角都不統一。
  4. **原生 OS 寫實立體 Emoji 泛濫**（`🟢 🐗 🗿 🌵 🦋 🦌 🎒 👻`）— 在精雕細琢的低面像素 3D 場景與羊皮紙框中顯得突兀廉價。
- **解法**：制定唯一的 **「🏮 燈谷手繪木框 × 羊皮紙設計系統（Lantern Craft UI）」**（詳見第二節）。

### 問題 3：彈窗結構與關閉鍵位置不一致
- **實機證據**：
  - 背包／靈魂／異界設計台：關閉鈕在**右上角**（寫 `關閉`）。
  - 技能拼圖（`04_ui_puzzle.png`）：關閉鈕跑到**左下角**（橘色按鈕孤立於左下）。
  - 鐵匠鋪（`07_ui_forge.png`）：無右上角關閉鍵，操作慣性斷裂。
  - 世界星圖（`08_ui_map.png`）：右上角寫 `✕`，且混用 `border-radius: 6px` 圓角。
- **解法**：所有彈窗一律共用單一 **Modal Header Shell**：左上「圖示＋標題」｜右側「相關貨幣」＋統一位置 **右上角 `[✕]` 方鈕**（全彈窗共用 `Esc` 關閉）。

### 問題 4：戰鬥 HUD 重疊打架（720p 實機已發生）
- **實機證據**：
  1. **區域大標題（Banner）與 Boss 血條（`#boss`）直接重疊**（於 `#15`、`#19`、`#20` 實機截圖皆可見標題文字壓在 Boss 血條上）。
  2. **右側三塊 HUD 撞車**：`#tideHud`（`top: 54px`）、`#autoHud`（`top: 174px`）與 `#comboBadge`（`top: 216px`）在掛機或連擊同時觸發時直接互壓！
  3. **底部技能列過長**：`#skills` 已擴增至 **10 格**（5 戰鬥＋5 功能），在 720p 下逼近左下角血條卡 `#pcard`。
- **解法（HUD 區域網格化）**：
  - 右側改為單一 **`#rightStack`（Flex Column 容器，自動垂直排列不重疊）**：依序放 `#tideHud` → `#autoHud` → `#comboBadge`，徹底消滅寫死 `top: 216px` 造成的重疊！
  - `#boss` 血條出現時自動下移或暫緩區域橫幅（Banner）顯示，或將區域小標題常駐整合進左上 `#topbar`。
  - 底部快捷列拆分為「**中央戰鬥 5 格（右鍵/Q/E/C/R）**」與「**右下精簡功能鈕（G/H/I/K/Z，縮小 15% 或採圓形角標）**」，拉開與左下血條的呼吸空間。

### 問題 5：核心系統的 UX 視覺回饋不足
- **技能拼圖（`04_ui_puzzle.png`）**：目前僅靠上方一行文字 `邏輯電路：右鍵 震擊 | Q 極光` 說明連動，缺少**棋盤格之間的「發光能量導線（SVG Circuit Glow）」**，看不出哪顆輔助石正在加持哪招技能。
- **物理背包（`03_ui_bag.png`）**：裝備比對需逐一點擊，缺少滑鼠懸停即顯的 **「新舊裝備對比浮卡（綠色 ▲ 提升 / 紅色 ▼ 下降）」**。
- **鐵匠鋪腐化改造（`07_ui_forge.png`）**：四種不可逆賭博結果僅寫成純文字，缺少視覺張力與機率分佈條。
- **怪物靈魂（`05_ui_souls.png`）**：目前用 Apple Emoji 代表 7 種靈魂，應換為統一風格的 **SVG 像素徽章／單色剪影圖示**，並標示「哪張地圖／哪隻怪會掉」。

### 問題 6：提示吐司（`#toasts`）資訊轟炸
- 切換到新異界時，「異界規則」、「地貌警告」、「地貌連鎖」、「山谷豐收」四條長文字吐司同時堆在左上角，字數過多玩家根本來不及讀。
- **解法**：限制同時最多顯示 **2 條精簡吐司**（超過自動合併或排隊），並將常駐型的「異界規則／地貌效果」交給左下角狀態膠囊（懸停顯示詳細說明），不再佔用吐司版面。

## 二、全遊戲統一視覺規範：《燈谷手繪木框 × 羊皮紙設計系統》

為了與 *A Short Hike*＋*Haven Park* 的溫馨 3D 低面像素美術融為一體，所有 UI（僅 `F3` 開發者除錯列除外，刻意維持 Godot 暗色工程感以區隔玩家介面）應全面統一以下 Token：

### 1. 色彩系統（Color Tokens）
| 用途 | Token / 色碼 | 說明 |
| :--- | :--- | :--- |
| **羊皮紙主底** | `--paper: #fff5de` | 所有視窗主背景（溫暖不刺眼） |
| **羊皮紙次底／卡片** | `--paper2: #f2e2be` | 內層卡片、裝備槽、未選中分頁 |
| **手繪木框墨線** | `--ink: #3b261e` | 統一 3px 實線邊框與 4px 硬陰影（`box-shadow: 0 4px 0 #2b1a14`） |
| **星燈暖金（主視覺焦點）** | `--gold: #f5b832` | 選中狀態、星火、航線、重要 CTA 高光 |
| **篝火橘紅（主要行動按鈕）** | `--cta: #d95a38` | 確認、出發、開啟副本、施放 |
| **森林松綠（正面／已套用）** | `--ok: #469454` | 已裝備、已套用、回復、正向屬性 |
| **深木半透明 HUD** | `--hud-bg: rgba(46, 32, 26, 0.88)` | **統一** `#topbar`、`#tideHud`、`#autoHud`、`#toasts` 的底色與 `2px solid #8a684a` 鑲邊（取消 `#autoHud` 獨立深紫色！） |

### 2. 幾何與邊角規範（Shape & Elevation）
- **統一微圓角像素感**：所有卡片與按鈕統一 `border-radius: 6px`（大彈窗 `10px`），廢除混用 `0px`、`4px`、`12px` 的雜亂感。
- **實體木牌按壓回饋**：所有可點擊按鈕皆具備 `box-shadow: 0 3px 0 #2b1a14`，`:active` 時 `transform: translateY(2px); box-shadow: 0 1px 0 #2b1a14;` 搭配清脆木擊音效。
- **圖示升級（去 Emoji 化路線）**：分批以輕量 **內嵌像素 SVG 圖示庫（16×16 / 24×24 crisp SVG）** 取代裝備槽、靈魂卡、貨幣（金幣／星砂／鑰石／羽毛）與主功能鈕上的系統原生 Emoji。

### 3. 全螢幕 HUD 黃金安全分區（720p 零重疊佈局）

## 三、分階段 UI/UX 翻新實作路線圖（Phase U1 ～ U3）

| 階段 | 重點目標 | 具體改造項目 |
