## 一、素材實機盤點結果（直接回答您的 3 個核心問題）

### 1. 底下的草地 assets 裡有嗎？
- **實機檢驗結果**：`Modular Cute Fantasy Character Pack 1 v1.1.unitypackage`（130 項資產）內僅含角色、裝備、武器、動畫與貼圖，**不含** Sketchfab 預覽用的草地微丘展示台模型。
- **1:1 還原方案**：我們將專為選角舞台打造一座**有機起伏的手繪感草地微丘展示台（`buildSculptedMeadowDiorama()`）**，完全淘汰目前生硬的圓柱＋八角台階＋圓球蘑菇花：
  1. **平滑高斯起伏草地微丘**：單一連續高細分圓盤網格，後方自然隆起柔和草坡（法師居高站立）、前方與右側平緩過渡（弓手、戰士、影刃、武僧自然圍立）。
  2. **512×512 手繪感草地＋彎曲泥土小徑貼圖**：程序化筆觸繪製鮮嫩青綠（`#a2e444 → #6cc232`）柔光草皮，搭配一條自右側蜿蜒繞過戰士腳邊的暖米色泥土小徑（100% 還原影片 `frame_01` / `frame_03` 視覺！）。
  3. **貼邊圓潤苔石＋纖細小黃花叢**：沿草盤邊緣與坡腳嵌入扁圓低矮暖灰苔石，點綴纖細深綠草莖＋五瓣小黃花叢（告別巨型蘑菇感）。
  4. **清透淺水藍底環**：緊貼草盤邊緣的一圈柔光水藍環帶，與純淨天青背景（`#95edf5`）自然融合。

### 2. 影片中的英雄 Pose 資產裡也有嗎？
- **有！全部都在我們已匯出的 5 套職業動畫（`anim_*.glb`）中！**
- 目前畫面之所以少了弓手「拉滿弓弦瞄準」等經典姿勢，是因為我們在選角頁統一只播放 `CombatIdle`；而在原包裡：
  - **🏹 林風遊俠 (Archer)**：拉弓搭箭瞄準 Pose 位於 `anim_archer.glb` 的 `attack` / `SkillAttack` 中段關鍵幀！
  - **🛡️ 守燈衛士 (Fighter)**：`CombatIdle` 即為低重心雙手持巨斧戒備架勢（對齊影片 `frame_03` / `frame_07`）。
  - **🔥 餘燼秘術師 (Mage)**：`CombatIdle` 即為站於草丘高處斜持藍晶法杖架勢（對齊影片 `frame_03`）。
  - **🗡️ 影刃行者 (Necro)**：`CombatIdle` / `CastLoop` 即為高舉秘刃酷帥架勢（對齊影片 `frame_03` / `frame_05`）。
  - **🪷 禪燈武僧 (Monk)**：`CombatIdle` 穩健執聖燈法杖架勢。
- **實作方式**：在 `src/char_anim.js` 新增 **`setShowcasePose(state, normTime)`** 靜態微呼吸展示模式（精準鎖定精華關鍵幀並保留極微幅呼吸起伏；點選英雄聚焦時再流暢播放完整出場動作，播完平滑回到招牌 Pose）。

### 3. 武器位置怎麼放好？（實機診斷與精準修復）
- **實機檢驗發現**：比對 `adventurer_base.glb`（49 個手部／武器骨骼）與 `anim_archer.glb`（31 個節點），確認部分武器子骨在匯出或待機動作間存在軌道缺漏，導致弓箭與部分武器在待機時出現手部微偏或箭矢浮空。
- **精準修復清單**：
  1. **Blender 武器骨骼完整性修正（`scripts/build_character_assets.py`）**：重新確認 5 份 `anim_*.glb` 完整保留所有 `Arm.hand.*`、`Equipment.weapon.*` 與 `Equipment.weapon.bow.*` 關鍵幀軌道，讓戰斧、長弓、箭矢、藍晶法杖、秘刃、聖燈法杖 **100% 緊貼雙手握柄**。
  2. **弓箭搭弦智慧顯隱（`src/char_rig.js`）**：獨立箭矢 `weapon_archerarrow_001` 僅於弓手拉弓／戰鬥／展示 Pose 時顯示，城鎮走路待機時自動收納回箭袋，杜絕浮空箭矢穿模。
  3. **換裝間與實戰對位逐一截圖驗收**：五職業正面／側面／近景逐一檢視雙手握持位置。

1. **總覽模式（Overview — 開場預設）**：
   - **草地小島居中放大**：小島與 5 位英雄穩居畫面正中央，四周是純淨清透的天青留白，滑鼠拖曳可 360° 絲滑慣性旋轉。
   - **真 3D 腳邊投影編號點（`1` `2` `3` `4` `5`）**：透過 `THREE.Vector3.project(camera)` 即時將編號小圓點投影到每位英雄腳邊（完全還原影片效果！），轉動小島時編號會真實跟隨角色前後遮擋與移動。

2. **聚焦特寫模式（Focus — 點擊 3D 角色、腳邊編號或 `◀ ▶`）**：
   - **影片級超近距離臉部＋武器特寫運鏡**：鏡頭於 `0.7s` 內以 Cubic-Ease-In-Out 平滑飛近，正面近距離欣賞英雄可愛大眼、髮絲與手上武器細節（對齊影片 `frame_05` / `frame_07` / `frame_09`！）。

     - 底部：旅人名字輸入欄＋`✨ 自訂外觀` & `🏮 提燈出發` 兩顆主按鈕
