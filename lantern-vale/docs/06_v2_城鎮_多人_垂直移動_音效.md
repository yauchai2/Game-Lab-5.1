# v2 更新說明：操作修正、垂直移動、音效、燈谷鎮與多人

## 1. 修正
- **WASD / E / R 偶爾失效**：原因是輸入法（IME，中文/粵語輸入）會改變 `event.key`。改用 `event.code`（物理鍵位），並在視窗失焦時清除按鍵狀態。
- **通道太窄過不去**：世界生成改為先「雕刻走廊」（flood fill 保證出生點到每個出口連通，並加寬到可通行寬度），再生成高度；樹木等障礙物不會堵路。

## 2. A Short Hike 式垂直移動
- 高低差山坡：平台高度 0 / 1.5 / 2.7，雙線性高度取樣 `gh()`。
- **Space**：跳躍；空中再按住 = **滑翔**（消耗體力）；貼著牆按住 Space = **攀爬**（消耗體力，頂端自動翻越）。
- 畫面左下新增體力條。Shift 為翻滾。

## 3. 音樂與音效
- 全部用 WebAudio **即時合成**（`src/audio.js`），沒有下載任何音檔。
- 理由：保持單一 HTML 檔、零授權風險、離線可玩。音樂分城鎮 / 探索 / 戰鬥 / Boss 四種，戰鬥強度隨敵人數量淡入。
- `M` 鍵或右上角按鈕靜音。

## 4. 燈谷鎮與多人（MMORPG 元素）
- 燈谷鎮：噴泉、房屋、告示板、攤位；出發口通往冒險。
- 村民 NPC：離線（例如 Artifact 內）時由機器人扮演，維持城鎮的熱鬧感。
- **多人伺服器**（`server/server.js`，Node + `ws`）：
  - 提供靜態檔案、在線名單、聊天（Enter）、表情、每區 10Hz 位置快照。
  - 區域：`town`、`title`、`run:<隊伍或單人>:<深度>`。
  - 啟動：`npm i ws && node server/server.js`，開 `http://localhost:8080`。
  - 客戶端只在 `window.LV_SERVER` 或網址 `?server=` 設定時連線。
- **限制（誠實說明）**：冒險地圖中的敵人由各客戶端本機模擬（共用種子），所以隊友是「同圖幽靈」可見、可聊天，但**傷害與掉落不是伺服器權威**。要做成真正合作戰鬥，下一步是讓房主模擬敵人、其他人同步。
- Claude Artifact 的 CSP 會擋 WebSocket，所以線上多人要在自己的電腦或主機上跑。

## 6. UI 風格（A Short Hike 參考）
- 參考：`reference/style/ash_snow_dialogue_bubble.jpg` 等（見 `reference/README.md`）。YouTube 影片當時無法從雲端環境存取，改以截圖為準。
- 做法：奶油色底、咖啡色字、**像素階梯邊框＋硬陰影**（純 CSS box-shadow，無圓角）、對話氣泡式提示、體力條改金黃色分段、過場改為步進式。
- 之後若要更貼近：改用真正的像素字體檔、羽毛形體力圖示、對話打字機效果。

## 7. 風吹草動、水波與設定頁
- **風**：草、花、灌木、樹冠用頂點著色器擺動（陣風沿 (0.82,0.48) 方向掃過，帶二階搖擺）；法線通道同步位移，描邊不會抖。地面草色另有緩慢移動的明暗色帶。
- **水**：淺水加 voronoi 白色細胞網、開放水面隨機擴散的雙圈漣漪，保留原有等高線與浪線。
- **設定頁**（Esc 或 ⚙）：畫面（像素大小、風吹草動、水波、光柱風線、畫面震動、傷害數字、聊天視窗）、音訊（主音量／音樂／音效／靜音）、操作說明、關於／重設。設定存 localStorage，開啟時暫停單機模擬。Tab/I 仍開背包。
