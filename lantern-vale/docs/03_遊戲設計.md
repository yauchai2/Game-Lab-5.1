# 遊戲設計：燈谷行 Lantern Vale

**類型**：俯視角動作 Roguelike（Path of Exile 2 式戰鬥與裝備 × Hades 式房間選路）
**氛圍**：溫暖、可愛、像素化 3D。戰鬥爽快但畫面舒服。
**主角**：燈芯（Wick），提著燈籠法杖的小旅人（深青色兜帽、紅橘圍巾）。原創角色。
**目標**：穿越 3 個區域、9 間房，喚醒/擊敗「古樹鹿王・歐爾德」。

## 1. 操作

| 鍵 | 動作 | 說明 |
|---|---|---|
| WASD | 移動 | 攻擊時減速 45% |
| 左鍵（按住） | 杖擊 | 120° 扇形近戰、擊退、hit-stop |
| 右鍵 | 餘燼彈 | 8 法力，火焰投射物，可多發/彈射/分裂 |
| 空白 | 翻滾 | 0.3 秒無敵，冷卻 0.85 秒 |
| Q | 根鬚重擊 | 天賦解鎖；範圍傷害＋暈眩 |
| E | 螢火群 | 天賦解鎖；環繞螢火蟲自動追擊 |
| R | 蜜藥瓶 | 1 秒內回 42% 生命；擊殺補充（POE 式） |
| F | 撿起並裝備 | 舊裝備會掉在地上，可再換回 |
| Tab / I | 角色面板 | 裝備、屬性、天賦 |

## 2. 一局流程

```
房間 1-1（教學難度，1 波）→ 清完選天賦（保證解鎖 Q）
  → 出現 2–3 座拱門，各標示獎勵：稀有裝備 / 天賦祝福 / 溫泉休憩
  → 走進拱門 → 新的程序生成島嶼（2–3 波敵人）→ 清完拿到該房獎勵 → 再選路
區域：1 晨光草原（1-1~1-3）→ 2 楓紅山徑 → 3 雪松高嶺 → 最終：餘燼古林・鹿王
死亡：顯示本局統計，重新開始（新種子）。最佳深度存在 localStorage。
```

## 3. 敵人

| 敵人 | 行為 | 讀招提示 |
|---|---|---|
| 苔蘚史萊姆 | 跳躍追擊、接觸傷害 | 擠壓彈跳動畫 |
| 刺藤樹樁 | 保持距離、發射荊棘 | 發射前抖動發光 0.55 秒 |
| 鬃毛野豬 | 接近後蓄力衝鋒 | 地面紅色長條 0.75 秒 |
| 燈蛾術士 | 繞圈、在玩家腳下放 3–5 個法陣 | 紫色圓圈 1.15 秒填滿後爆炸 |
| 精英（隨機） | 體型 ×1.35、血量 ×2.6、多發投射物 | 金色腳下光環，必掉魔法以上裝備 |
| **古樹鹿王（Boss）** | 衝鋒連段、環形彈幕、根鬚地刺、踐踏、召喚；半血進入二階段（更快、更多） | 全部有地面預警 |

數值成長：每深一層 HP ×(1+0.22)、傷害 ×(1+0.12)，每波數量 3 + 0.7×深度。

## 4. 裝備（POE 式）

- 欄位：法杖（隱含：基礎傷害）、斗篷（隱含：生命）、護符（隱含：暴擊）。
- 稀有度：普通（0 詞綴）、魔法（1–2）、稀有（3–4）、傳奇（固定特效）。地上有對應顏色的光柱。
- 詞綴池：傷害%、附加火焰、攻速、暴擊率、暴擊傷害、生命、擊中回復、移速、冷卻縮減、法力、範圍、減傷、生命回復、餘燼彈 +1（稀有限定）。數值隨 tier（深度）成長。
- 傳奇：野火之杖（彈分裂）、鹿骨權杖（揮擊放衝擊波）、苔心大氅（每秒回 2%）、月蛾護符（翻滾留冰環）、螢火之心（螢火 +3）。
- 撿取提示會顯示與目前裝備的比較分數（▲/▼）。

## 5. 天賦（房間獎勵，三選一）

大地之根（解鎖 Q）、螢火伴隨（解鎖 E）、連鎖火花、分焰（可疊）、厚苔（可疊）、疾風步、月相、野宴（可疊）、玻璃燈罩、荊棘外衣、餘震（需 Q）、蜂擁（需 E）、蜜酒葫蘆、輕盈、銳眼。

## 6. 回饋與手感（Game feel）

命中白閃、hit-stop（0.02–0.06 秒）、鏡頭震動、擊退、飄字（暴擊金色放大）、死亡碎塊＋白煙、掉落光柱、翻滾煙塵、走路腳步煙、低血量畫面邊緣紅色脈動、房間轉場圓形擦除。
