# 燈谷行｜開局首 10 分鐘複查與下一輪規劃

2026-11-26 · 本機建置 `88e5263be487`

## 設計目標

玩家在首趟親手點亮一盞燈，看懂一次敵人出招，用自己選的寶石改變一次戰鬥，最後帶著目前用得到的成長離開。沿用角色海島、像素小提燈、雙路線、洞窟檢查點及巡燈徽章。優先改善第一次能否看懂、做到，以及回來有沒有下一步。

## 本輪證據

- 以守燈衛士從瀏覽器進場，按預選出發，打開巡燈任務，實際檢查跟隨燈火和直接前往南門兩個入口。以正常鍵盤移動和互動點燈，靠近幼狂豬及嘗試出招。當場目睹協助回饋、靈魂與連擊提示同時出現，敵人資訊顯示 `Lv.undefined`。未量度第一次打贏所需時間。
- 以新瀏覽器環境重跑手機 390 × 844 任務光路、跨區、關閉與重開、點燈後換目標。手機回歸使用模擬觸控，點燈後進度經由測試安排位置。
- 洞窟回歸核實鑰石、各段、首領預警、重讀續打、通關單次結算及手機工坊。雙分頁回歸核實寶石與徽章各只發放一次。洞窟回歸以測試定位及高傷害覆蓋系統狀態，工坊後段亦使用測試資源。畫面可用來檢查版面和資訊層級。輸入難度、耗時、首通等級、真人理解及回訪需要另外實測。Dev Mode 沒有新的待審事件。
- 舊版自動試玩摘要屬建置 `99c648ccbbf5`，涵蓋其他試玩情境。本輪結論依上述新觀察與回歸。

## 分段審查與體驗規格

| 步驟與規劃時間 | 目前體驗 | 下一輪規格 |
| --- | --- | --- |
| 1 · 0:00–0:30 選旅人 | 預選旅人可以直接出發。窄視窗的遊戲標題、登入和設定出現換行，五個數字只提示可切換，職業手感需自行猜。 | 保留海島與預選出發。預選名字底下加一句玩法差異，例如「近身穩守 · 聖劍震暈」，每次只顯示所選職業。窄屏把存檔和登入收到次要區域，鍵盤焦點先到可切換的旅人，再到出發。 |
| 2 · 0:30–1:30 第一次點燈 | 任務卡、指南針都有目標。光路可認出，轉區也會接續。面板同時有兩個綠色按鈕「跟隨燈火」和「前往南門」，後者直接傳送。手機截圖中，居民名牌疊到角色及路線。實際接近後才見到 F 提示，這個時機可保留。 | 新角色首次打開任務只突出「跟燈去草原」，把「直接傳送到草原南門」做次要動作，光路開關放同一位置。城內用地區目的地「前往晨光草原」，進草原才用地標「點亮南門路燈」。保留虛擬居民的活動，起點數秒內收起重疊的遠處名牌，只突出自己、任務與當前互動。點亮後給聲音、光色和簡短文字三種回饋。 |
| 3 · 1:30–2:45 幼狂豬 | 已有直線前搖及 1.2 秒收招。實際看到其他系統提示佔據畫面，且敵人資訊曾出現 `Lv.undefined`。場景小提燈會追正在移動的敵人，與戰鬥訊號在同一位置。現行練習以擊倒為完成條件。 | 只在接戰前顯示光路，首次前搖切到清楚的條形預警和操作提示，收招於敵頭上顯示短暫「反擊」指示。觸控用「橫推搖桿＋翻滾」，鍵盤用目前綁定按鍵，語音或音效作輔助。抑制首戰進行中的居民協助、戰利品與連擊彈窗，把已獲回饋留在紀錄；未提供有效等級的敵人就省略等級。記錄有沒有躲過及在收招時打中，維持自由擊倒或略過的出口。 |
| 4 · 2:45–4:40 分路與第一顆寶石 | 重燃路燈的主要互動與清剿前哨不同，兩線匯入同一首領。領獎存在可恢復收據與一鍵安裝。 | 調查線用地標繞路與點燈，清剿線用距離管理與優先處理射手。兩線最少有一個會再次讀到的直線攻擊。代表變化留給首領，只在已學模式上加一個新反應。領獎先顯示職業技能名稱和兩個實際結果「命中後減速」或「缺血時命中回血」。先集中「裝上寶石」再「試打一場」，保留手動配置。 |
| 5 · 4:40–7:45 草原洞窟 | 三段編排及重新整理續打已通過。截圖顯示首領名、入場卷軸、部位提示貼在同一條上方區域。野外首領、洞窟第二段及洞窟首領多次使用狂豬語彙。 | 第一段安排可隔開的射手及近戰怪群，給霜緩創造距離、汲血在真實缺血時回血的機會。技能首次有效時在技能旁提示一次。第二段原型保留，若真人重複同一解法便縮短成一組短伏擊。洞窟首領用腳下重踏和地形改變位置。戰術在出手前提示，出手時只保留血條與危險輪廓；回來時顯示已付鑰石及接續段落。 |
| 6 · 7:45–8:45 首通徽章 | 可打造立即穿戴或放入背包。洞窟結算引到一般素材工坊，手機工坊同屏有幣種、素材及其他配方，且現有入口會帶上戰杖配方。 | 先展示徽章、實際傷害變化及穿戴位置。已有飾品時顯示比較，留給玩家自行選用。確認獎勵後才顯示完整工坊。保留既有扣料／領獎順序、Lv.2 條件及單次收據。 |
| 7 · 8:45–10:00 下一站 | 工坊可開下一站。現時兩個推介均標示建議 Lv.5，精英另要鑰石。程式在同一階段亦有建議 Lv.3 的晨光精英遠征。 | 以實際角色等級與鑰石排建議。近期可做的選擇用晨光精英遠征或留在安全區強化。森林先給短目標和新怪招示範，想越級的玩家可直接前往。精英洞窟顯示手上鑰石及取得來源。玩家停下時在任務卡留下所選下一站。 |

上述時間是內容配置窗口，以看懂並完成一次主循環為優先。首通即停、先逛城鎮或自選遠征都應有可以重拾的路線。

## 三個交付階段

1. **P0 · 首三分鐘清晰可操作。** 在現有 `openingStep()` 上透出共用目標與動作，讓任務卡、指南針、光路和教學文案讀同一狀態。共用光路在首戰接戰時收起，戰鬥提示有優先權，敵人 UI 檢查缺失欄位。修正窄屏標題及首領血條重疊。先測 390 × 844 直向、窄視窗及桌機。驗收為初始兩個入口有明確結果、第一戰畫面只突出演示中的動作、離開再回來仍能找到同一目標。
2. **P1 · 讓新手自己感受到變強。** 從實際預警、躲避、收招命中與寶石效果事件推進回饋。徽章使用一張聚焦結算卡。從現有遠征、寶石實例、洞窟與背包資料讀進度，保存已付鑰石、檢查點、單次收據及舊檔相容。若玩家裝備欄已有飾品，只在玩家確認時替換。
3. **P2 · 依真實操作調時間與分支。** 先試現有三段與縮短中段的候選，分別對照每段停留、死亡點及寶石首次生效。依角色狀態加入下一站推介。多人驗證首戰敵人歸屬及教學提示篩選，測完離開再回原分流。

## 驗收與記錄

- 真人首輪用同一建置找六位首次玩家，至少包含桌機、iOS 和 Android。請他們自行玩十分鐘，記下第一次停住、誤按和開口求助的位置。第一輪目標為至少五人自行出發及點亮第一盞燈，至少四人完成首戰並實際觸發一顆寶石或穿戴徽章。記錄第十分鐘在哪、為何停下、下一次是否願意回來。將六人資料用於定位問題，回訪用後續試玩的實際行為驗證。
- 自動操作至少覆蓋近戰、遠程、兩條遠征、兩顆寶石、有／沒有鑰石、已穿飾品、舊存檔及中斷續打。正常輸入測試用來觀察操作與通關。傳送位置及高傷害回歸用於快速驗證狀態、獎勵與跨分頁行為。各自保存結果。
- Dev Mode 補記首次可操作、任務打開、到燈旁、點燈、首個預警、首個成功閃避、第一次收招命中、首次寶石有效、洞窟段落、徽章處置及下一站。用當次測試識別碼串起建置、輸入方式、失敗位置與診斷。靜音及減少動態效果仍須能辨認招式。
- 優先用本輪重現案例驗收。保留一鍵出發、光路跨區、雙分頁獎勵及同票續打的既有通過案例。
