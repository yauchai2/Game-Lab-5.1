> **規劃日期**：2026-11-24  
> **適用版本基準**：`feat/visual-overhaul`（Phase 5C，20 張野外島嶼＋2 主城＋三層星燈星圖＋餘燼潮汐＋提燈巡遊）  
> **文件性質**：永久系統設計與架構藍圖（供日後啟動線上化開發時作為核心依據）

## 一、現況總診斷：為什麼現行單機版不能直接上線當 MMO？

目前專案已具備 `src/net.js`（WebSocket 位置同步與聊天室）與 `src/guild.js`（公會錢包與共鳴樹庭 Boss Raid 原型），但本質上仍是**「客戶端權威（Client-Authoritative）的單機架構＋社交外殼」**。若直接對外上線成為 MMO，會立刻面臨四大結構性危機：

1. **存檔與經濟零防禦**：角色等級、金幣、星砂、裝備、拼圖寶石與靈魂全部存於 `localStorage`（`src/meta.js`），任何玩家打開 F12 即可 1 秒改出神裝與無限金幣，經濟系統將瞬間歸零。
2. **戰鬥與掉落全由前端運算**：傷害公式、暴擊、怪物血量、裝備掉落與腐化結果都在瀏覽器端執行，外掛可輕易實作「一刀秒殺全圖」、「瞬移吸怪」與「100% 傳說掉落」。
3. **20 張野外地圖各自不同步（Desync）**：目前只有主城與 Guild Raid 同步位置；20 張野外地圖的魔物生成、部位破壞、地表元素區、餘燼潮汐都是各個客戶端獨立運算，玩家彼此看不到同一隻怪。
4. **開發者工具暴露**：`window.__game` 與 `src/debugger.js`（無敵、零 CD、刷傳說裝）目前直接打包在 `game/index.html` 中，正式線上版必須透過建置旗標（Build Flag）於編譯期徹底剝離。

## 二、現有單機玩法在 MMO 環境下的 7 大衝突點與改造方案

以下逐一盤點《燈谷行》目前最受歡迎的核心系統，分析「變成多人同時在線後會出什麼事」以及具體的玩法改造設計：

### 1. 餘燼潮汐（`src/tide.js`）與 360° 怪海
- **MMO 衝突點**：
  - 單人觸發 360° 怪海已經有 40–60 隻怪；若同張地圖有 25 名玩家各自推進潮汐，全圖將瞬間爆出 **1,200+ 隻魔物**，伺服器 CPU 與玩家前端 FPS 雙雙崩潰。
  - A 玩家辛苦堆高潮汐熱度叫出潮汐王，B 玩家路過搶尾刀或被捲入圍毆，體驗極差。
- **MMO 改造方案**：
  - **改為「全區共享・世界餘燼潮汐（Zone-Wide Ember Tide）」**：同一分流內所有玩家的擊殺共同推動該島嶼的潮汐熱度條（晨光 → 火星 → 狂潮 → 熾炎巔峰）。
  - **世界潮汐王（World Tide Boss）**：熱度滿 100% 時，在該區地標廣場降臨巨型「強化潮汐王」（血量依現場人數動態縮放），全場玩家一起圍攻。
  - **集體潮退休整營火**：擊敗後全區同時進入 25 秒歡樂休整，中央升起巨型共享營火與個人獨立戰利品寶箱，陌生人一起坐下回血、發表情符號，完美契合《燈谷行》溫馨調性！

### 2. 環境元素連鎖反應（`src/elements.js`）與特殊地貌
- **MMO 衝突點**：
  - 玩家 A 鋪了「極寒冰面」想打碎冰，路人 B 隨手丟一顆火球把冰融掉變成蒸汽；多人同屏放技能會造成地表不斷互相覆蓋（無意間互相干擾 / Griefing），且連鎖爆炸傷害算誰的？
- **MMO 改造方案**：
  - **非破壞性「跨玩家協同連攜（Co-op Synergy）」**：其他人鋪的水窪、冰面或毒霧**不會被你的技能消滅**，而是對你觸發一次**額外的協同元素爆發**，並同時給「鋪場者」與「引爆者」彈出 **`✨ 協同連攜！傷害 +15%`** 提示與助攻積分！
  - **特效降噪（Visual Clutter Culling）**：他人施放的技能粒子與地表透明度自動降至 **35%–45%**，保留自己與 Boss 紅圈為 100% 清晰度，避免 20 人同屏時畫面全白。

### 3. 提燈自動巡遊掛機模式（`src/autopilot.js`）
- **MMO 衝突點**：
  - 在單機很治癒的掛機模式，上了 MMO 會直接引發**兩大災難**：
    1. **工作室多開腳本農場（Bot Farms）**：就算收益只有 30%，工作室開 100 個分頁掛 24 小時也能洗爆全服金幣與拍賣行。
    2. **野外怪點被掛機軍團霸佔**：活人玩家進圖發現滿地都是自動打怪的角色，毫無探索與刷怪空間。
- **MMO 改造方案（三道防線）**：
  1. **掛機產出全面「帳號綁定（Account-Bound）」**：巡遊期間獲得的金幣改為「綁定旅人幣」、素材與裝備不可交易也不得上架拍賣行，徹底斷絕工作室獲利動機。
  2. **每日「提燈油量（Daily Lantern Oil）」上限**：每位玩家每日提供 **2 小時免費掛機額度**（可透過手動完成每日委託補充 +30 分鐘），油量耗盡自動回城休整，杜絕 24 小時佔線。
  3. **幽影巡遊位面（Phase-Shifted Solo Layer）**：開啟 `[Z]` 提燈巡遊後，角色視覺上化為半透明「提燈幽影」，進入獨立輕量巡遊層（或在獨立刷怪池結算），**完全不搶奪手動活人玩家的野外魔物**，同時保留「🔥 手動星火 ×1.5 歸來爆發」鼓勵玩家手動接管！

### 4. 20 張超大野外地圖與「人口稀釋（鬼服感）」
- **MMO 衝突點**：
  - 目前有 **20 張 540m–660m 野外島嶼＋2 座主城**。如果同時在線人數為 100–300 人，平均每張超大圖只剩 5–10 人，跑半天遇不到半個活人，完全不像 MMO。
- **MMO 改造方案**：
  - **動態分流合併（Dynamic Sharding）**：每個區域單一分流目標容納 **15–25 人**；人少時自動合併至單一分流，超過 30 人時才開新分流（組隊隊友優先同分流）。
  - **三層星圖「巡迴聚焦熱點（Hotspot Beacons）」**：每 30 分鐘系統在三層星圖中隨機點亮 **2 座熱門島嶼**（給予「🔥 餘燼金潮：經驗＆掉寶 +40%」或「🍗 旅人食物夜市」），自然將全服活人玩家聚集到少數熱點一起同樂，其餘 18 張圖則作為安靜探索／解任務／採集的秘境！

### 5. 動作手感衝突：頓幀（`hitstop`）、部位破壞（`src/parts.js`）與低重力
- **MMO 衝突點**：
  - `hitstop`（擊中頓幀）若暫停世界會讓全服卡頓；多人圍毆同一隻巨像／鹿王時，誰打斷鹿角誰拿專屬武器會引發搶裝糾紛。
  - 深海沉淵（`low_gravity`）與高速滑冰（`ice_lake`）的物理慣性若全由伺服器硬校正，網路延遲 >80ms 時會一直「拉回（Rubber-banding）」。
- **MMO 改造方案**：
  - **本地視覺頓幀（Local Hitstop）**：`hitstop` 僅暫停「攻擊者自己的揮擊動畫與粒子 45ms」，絕不影響伺服器世界時鐘與他人移動。
  - **共享部位血條＋個人獨立掉落（Shared Tagging & Personal Loot）**：任何參與攻擊並造成 ≥3% 傷害的玩家，於怪物死亡或部位斷裂時皆獲得 **100% 獨立經驗與個人專屬掉落物**（別人看不到也撿不走），徹底根除搶怪與搶裝戾氣！
  - **寬鬆客戶端預測（Client-Side Prediction）**：滑冰、低重力跳躍、滑翔由前端即時運算保證絲滑手感，伺服器端改採「依地形微規則動態放寬最大速度包絡線（Velocity Envelope）」進行反加速外掛校驗，而非逐幀強制拉回。

### 6. 遊戲經濟、裝備腐化與通膨控制（`src/loot.js`、`src/physbag.js`）
- **MMO 衝突點**：
  - 目前裝備掉落多、升級快，且缺乏「資源消耗槽（Gold/Item Sink）」，上線兩週後全服就會滿街神裝、金幣貶值。
- **MMO 改造方案**：
  - **分級交易制度**：普通～稀有裝備、採集素材、基礎拼圖寶石可於公會市集／拍賣行自由交易（收取 **8% 金幣交易稅** 回收通膨）；**傳說／神話裝、腐化成品與怪物靈魂**採「拾取綁定」，維持核心遊玩價值。
  - **把「裝備腐化（Vaal Corruption）」與「終局異界圖鑑（Atlas）」當成天然 Item/Gold Sink**：高階玩家追求極品詞綴時會主動腐化裝備（具損毀風險）並消耗金幣／鑰石製作高詞綴異界門票，讓市場對基礎胚裝與材料永遠保持需求。
  - **伺服器端驗證物理背包合成**：前端保留好玩的物理碰撞動畫，但實際合成結果、物品 UID 與詞綴一律由伺服器簽發。

### 7. 社交與合作動機（打造真正的「溫馨荒誕派 MMO」）
既然《燈谷行》的美術是 *A Short Hike*＋*Haven Park* 的療癒像素 3D，就別做成硬核內捲的競技 MMO，而要放大**「陌生人互相點燈」的溫暖社交**：
- **營火共食系統（結合 `4291 食物包`）**：任何玩家在野外生起營火並擺上料理，路過陌生人坐下來一起吃即可共享 30 分鐘 Buff，並可按一鍵「🏮 贈送星火」給主廚增加聲望與外觀解鎖進度。
- **4 人小隊「星燈羈絆」**：組隊挑戰副本或異界圖鑑（Atlas）時，隊友靠近彼此獲得移動與回魔光環，死亡時隊友可靠近按 `F`「點燈拉起（Revive）」免於回城！
- **燈谷鎮＆海風港鎮「外觀社交舞台」**：把造型工坊、坐騎收集、披風染色與季節限定頭飾做成核心長期追求（無數值 Pay-to-Win）。

## 三、MMO 技術架構升級藍圖（獨立團隊可維護方案）

### 1. 推薦後端架構（Server-Authoritative）
| 層級 | 建議技術 | 職責說明 |
| :--- | :--- | :--- |
| **前端（Client）** | 現有 Three.js + esbuild（維持 270p Pixel-Toon） | 負責渲染、前端預測移動（Prediction）、其他玩家快照插值（100ms Interpolation Buffer）、本地視覺頓幀與特效。**建置正式版時透過 `DEV=0` 旗標完全剝離 `debugger.js` 與 `window.__game`。** |
| **即時遊戲服（Zone Server）** | Node.js（TypeScript，可複用現有 `src/field_blueprints.js`、`src/loot.js`、`src/elements.js` 邏輯！）或 Go | 每個 Zone 實例以 **15–20 Hz Tick** 權威模擬怪物 AI、技能命中判定、掉落結算、世界潮汐與速度防作弊檢查。 |
| **興趣區域裁剪（AOI）** | 30m × 30m 空間網格（Spatial Hash Grid） | 每張 360m 地圖僅向客戶端同步周圍 3×3 格內的玩家、怪群與投射物狀態，網路頻寬降低 **85%–90%**，同區輕鬆撐住 40+ 人。 |
| **通訊協定** | WebSocket + 二進位編碼（MessagePack / FlatBuffers） | 取代目前的純 JSON（`src/net.js`），單幀位置封包從 ~120 bytes 壓縮至 ~18 bytes。 |
| **資料庫＆快取** | PostgreSQL（核心存檔／交易）＋ Redis（在線分流／聊天／拍賣鎖） | 取代 `localStorage`；裝備交易與合成採資料庫交易鎖（ACID），杜絕複製物品 Bug（Dupe）。 |

### 2. 安全與防作弊底線
- **零信任前端（Never Trust Client）**：前端只送「輸入意圖」（移動方向、施放技能槽位、瞄準角度、互動目標 ID），伺服器計算實際冷卻、魔力、命中與傷害。
- **速度包絡線防加速**：伺服器依據玩家當下的坐騎、地貌（冰湖 +38%）、異界規則（滑沙 +24%）計算合法最大位移，超標自動修正並記錄異常分數。
- **原子化交易與拾取**：每個掉落物帶唯一伺服器 `dropId`，撿取後立即標記已領取，防並發封包刷裝。

## 四、務實分階段線上化路線圖（Phase M1 ～ M4）

不建議一口氣從單機跳到萬人 MMO，建議依序推進，每個階段都可獨立上線試玩：

| 階段 | 目標定位 | 核心實作項目 |
| :--- | :--- | :--- |
| **Phase M1：雲端帳號＋4 人小隊 Co-op** | 最快驗證多人手感 | 帳號登入與 PostgreSQL 雲端存檔（取代 `localStorage`）；房間制 1–4 人同步打副本、Boss 與野外；共用部位破壞＋個人獨立掉落。 |
| **Phase M2：權威區域服＋世界潮汐** | 真正的大世界多人同屏 | 建置 Zone Server + 30m AOI 網格；將 `src/tide.js` 升級為全區共享世界潮汐王；實作跨玩家元素協同連攜與他人特效降噪。 |
| **Phase M3：經濟系統＋防工作室巡遊** | 可長期營運的經濟循環 | 公會市集／拍賣行（8% 稅率＋ACID 鎖）；`src/autopilot.js` 接入「每日提燈油量＋綁定資源＋幽影位面」；正式版剝離開發者模式。 |
| **Phase M4：動態分流＋星圖巡迴熱點** | 解決人口稀釋與長線留存 | 動態分流合併（15–25 人/區）；三層星圖每 30 分鐘輪換「餘燼金潮／美食夜市」熱點；主城營火共食與外觀社群系統。 |
