# 燈谷行怪物戰鬥規劃

目標是讓玩家看得出怪物接下來要做甚麼，能用走位、打斷、跳躍或部位破壞應對。同一家族的變種共用可辨認的基本招式，再用移動節奏、出招角度或地形效果改變打法。

## 現有基礎

目前 `spawnEnemy` 按怪物類型設定血量、移速和模型，`updateEnemies` 負責追擊、蓄力、出招和硬直。棘芽射手會拉開距離，野豬有直線衝鋒，月影飛蛾會在玩家身旁布置落點，星晶巨像有蓄力重擊，雲翼飛鰩可以被空中截擊。精英已有詞綴，守護獸已有階段與部位破壞。許多地圖共用上述行為，只換成不同的模型。

低語森林遠征先以鉤棘老根試作兩個能分辨的攻擊。落根圈鎖定玩家蓄力當下的位置，1.1 秒後檢查同一圈的命中，接著進入短硬直，再準備扇形三連棘刺。森林伐木道也加入野豬、射手和飛蛾，讓玩家在近戰衝鋒、遠程攻擊與落點封路間切換應對。

霧潮沼澤首領「孢囊巨像」已加入預警圈、敵方毒池與可引爆的火焰反制。破壞背側孢囊會縮小後續毒池。首通結算才發放破部位追加鱗粉，以同一場擊敗首領的戰果為準。

## 家族、速度與攻擊形態

表內速度是各家族現有基礎移速的試玩倍率。衝鋒與俯衝速度獨立設定，受寒霜等減速效果時依現有規則計算。

| 青苔史萊姆 | 平時 0.85×，短躍加速 | 蹲低後跳撲固定落點。橫移避開落地圈，趁落地硬直反打 | 沼澤種落地留短暫毒池，讓玩家決定換位或點燃毒池 |
| 棘芽射手 | 0.95×，邊退邊繞 | 停步亮起尖刺後射擊。後期交替使用直線瞄準彈與扇形散射，兩招有不同前搖 | 森林種交替走位和三連發；雪地種用慢速冰針封一側退路 |

## 實作順序

1. **晨光草原試作。** 讓史萊姆、棘芽射手、野豬各有一招能辨認的主攻。沿用現有圓形與矩形地面預警、投射物和部位系統。驗證新角色用步行、翻滾都能應對，每種怪都有清楚的反打時間。
2. **低語森林、霧潮沼澤與霜冬雪原。** 加入射手散射、毒池、巨像震波與雪原衝鋒變體。巡邏群由近戰壓迫、遠程封路或重型守點組成，小隊同時最多一次主要控場。先測一組玩家必須選擇優先目標的編隊，再把組合推到其他區。
3. **空戰與高階區域。** 完成飛鰩俯衝、飛蛾錯時落點、區域精英連招。精英增加一個招式或改變出招順序，並讓元素詞綴有獨立而可辨認的提示。加入水面感電、毒池爆燃、冰帶等現有地表連鎖。
4. **守護獸、世界王與全圖調校。** 按各島守護獸的模型及地形配置代表技，再比較單人刷圖與 36 名虛擬玩家在場時的戰鬥節奏。世界王的主要預警和玩家職業特效要同時可讀。

## 實作與驗收

- 將追擊、預警、出招、硬直的節奏交給共用狀態流程。每招配置觸發距離、形狀、鎖定時點、傷害、冷卻和部位影響。首輪主攻預警可從 0.7–1.0 秒試起，重招留更長時間。預警圖形與命中範圍使用同一組參數。
- 保留 `type` 對圖鑑、掉落、異常狀態及弱點的對應。擴到區域變種時，將變種識別寫入野外狀態和重生資料。舊紀錄依怪物家族回退到基本行為。切圖、死亡或技能被打斷時清除相應預警和延遲命中。
- 驗證衝鋒鎖定後可側閃、冰帶命中和畫面一致、部位破壞影響下一次攻擊、飛鰩可被截擊、怪物死亡後待取消的招式不再命中。強控場的提示同時用形狀與動作表達，讓玩家在多個特效疊加時仍能讀招。
- 用相同鏡頭、畫質和路線比較晨光草原營地、單一精英與世界王戰。記錄更新與渲染幀時、同時預警數、實際場景通道的 draw calls。36 名虛擬玩家與戰鬥特效同場重測，優先重用預警材質並限制遠處怪物的決策頻率。
