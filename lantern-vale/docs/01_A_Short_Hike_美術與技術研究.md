# A Short Hike 美術與技術研究

> 研究材料：Alan 提供的 9 張參考圖（4 張 A Short Hike 遊戲截圖、2 張 shoejaat "Little Joy" 渲染、1 張草地小場景、2 張其他）、`x-downloader…mp4`（16 秒、2160×2160、俯視森林小屋與河流），以及公開資料中關於 A Short Hike（adamgryu，2019，Unity）的已知做法。
> 本文件只研究「風格與技術手法」。我們的遊戲不使用 A Short Hike 的角色、名稱、關卡或素材。

## 1. 一句話總結

**低多邊形 3D 場景 → 以很低的解析度渲染（約 270–360px 高）→ 最近鄰放大成像素畫**。再加上：平塗（toon）光影、描邊、手繪感水面、暖色調、斜射光束。結果是「看起來像像素畫，其實是 3D」，所以鏡頭能動、光影是真的，卻保有像素美術的溫度。

## 2. 視覺拆解（逐項對照參考圖）

| 元素 | 觀察（參考圖） | 技術推測 / 對應做法 |
|---|---|---|
| 像素化 | 截圖 1900px 寬，一個「像素」約 4px → 內部解析度約 475×270 | 渲染到低解析 RenderTarget，`NearestFilter` 放大；不開 MSAA |
| 低多邊形 | 樹＝幾個錐體疊起；岩石＝少面數塊體；地形有明顯三角面 | 程序生成或手工 low-poly，**平面著色（flat shading）**，面數極少 |
| 光影 | 亮面、暗面兩到三階，邊界銳利；陰影偏紫藍不是黑 | Toon ramp（2–4 階梯度圖）＋偏冷色的環境光（天空色偏紫藍） |
| 描邊 | 物件剪影有深色細線（截圖 2 的懸崖、截圖 5 的小屋） | 後處理：深度不連續處把「較近的一側」變暗；法線摺痕微亮 |
| 懸崖 | 灰紫岩壁，有水平/斜向條紋筆觸 | 依高度/噪聲分條帶上色，坡度大於閾值即視為岩壁 |
| 草地 | 兩三種綠的大色塊（不是逐格雜訊），上面散落 "Y" 形草叢筆觸、小花點 | 低頻噪聲分區上色＋實例化的小草叢、花 |
| 小路 | 橘褐色泥土路，邊緣柔和不規則 | 依「距離路徑線段」上色，邊緣加噪聲 |
| 水 | 深藍＋淺藍等高線般的漩渦線、岸邊白色泡沫粗線、外圍一圈淺色 | 自訂水面 shader：離岸距離場（distance field）→ 深淺漸層、泡沫邊、往外推的浪線；fbm 等值線畫漩渦 |
| 光束 | 畫面斜向的淡黃光帶、細白風線（截圖 2、3、影片） | 螢幕空間後處理：斜向帶狀噪聲疊加暖光；稀疏白色細線 |
| 調色 | 高飽和暖色：秋季橙紅、夏季黃綠、雪地淡紫 | 每個區域一套調色盤＋整體暖色 grade、輕暗角 |
| 雲影 | 影片中大塊緩慢移動的陰影 | 後處理以深度重建世界座標，fbm 雲遮罩乘暗 |
| UI | 奶油色對話框＋深色粗邊、像素字體 | HTML 疊層、DotGothic16 字體、圓角奶油面板 |

**影片（Little Joy 類型的高解析版）**的差異：沒有像素化、陰影較柔、有體積光和反光，這是同一套美術語言的「高解析版本」。我們選擇 A Short Hike 的低解析路線，因為它成本低、在網頁上效能好、像素化本身就會吃掉模型粗糙處。

## 3. A Short Hike 已知的技術手法（公開資訊整理）

- 引擎：Unity。作者在 GDC / 社群分享中提到用「低解析渲染 + 點取樣放大」，並可在設定裡調整像素大小（我們也做了「細／標準／粗」三檔）。
- 角色與場景都是簡單 3D 模型 + 手繪風格貼圖/頂點色，不依賴高解析貼圖。
- 鏡頭為固定俯角、會依地形改變距離與角度的跟隨鏡頭。
- 描邊與水面是自訂 shader；像素化讓這些 shader 的鋸齒反而成為風格。

## 4. 我們要保留 vs 要改的

保留：低解析像素化、toon 光影、描邊、手繪水面與泡沫、光束、暖色調、溫柔的 UI 與小巧角色。

改變（為了 Roguelike / POE2 玩法）：
- 鏡頭改為**固定俯角 ARPG 視角**（約 54° 俯角、FOV 30），稍微往滑鼠方向偏移，方便瞄準。
- 世界改為**程序生成的島嶼房間**（每間一座小島＋高台懸崖＋出口拱門），而不是開放世界。
- 戰鬥可讀性優先：敵人攻擊預警用地面紅/紫色圈、直線，命中有白閃、停頓（hit-stop）、震動、飄字。
