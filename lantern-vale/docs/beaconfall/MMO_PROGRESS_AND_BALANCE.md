# Beaconfall · MMO 成長、平衡與耐玩度

**狀態：待原型驗證。** 本文件記錄設計方向、首輪試玩數值、驗收門檻和擴展順序。下文的時間與倍率是調校起點，實際結果須以新角色、現有角色與多人試玩量度。

## 1. 核心決策

- **角色初期偏弱，靠操作和小幅成長站穩。** 初始角色可處理同級單一敵人，兩種威脅同時來時就要選站位、先後次序和出手時機。
- **第一次改招要早出現，威力可以小。** 下一次出手多一支箭、一圈波或一件投射物，立即看得出變化。升級主要先改善覆蓋、選擇和容錯；同級單體輸出慢慢增加。
- **改招永久跟角色。** 學會的分支在跨區、重登和出副本後保留。初版同時啟用一條職業普攻分支，之後可在安全點換配置。武器提供基礎攻擊，拼圖仍配置主動技能。
- **一種新戰鬥問題至少有一個地方介紹、一個地方練習、一個地方驗收。** 前哨、公共事件和副本分別承擔這三個角色。重要解鎖提供常駐路線。
- **每次登入有短目標和自然停點。** 可以打一個小目標收工，亦可以和朋友打完整事件。回訪靠已有招式的新用途、可試的分支及多人協作。

## 2. 先量基線，再鎖首測數值

固定測試條件為標準難度、同等級敵人、當級普通品質裝備、無外部 Buff。遊俠與衛士各量一次。以首次進入戰鬥到最後一擊計時；分別記錄貼身與正常射程、單體與三敵分布。角色成長比較另用一隻固定測試敵人，區分攻擊本身變強同敵人等級變動。

開局規格曾記錄標準幼狂豬 67 HP、普通攻擊約 1.06 秒一次。這是舊測點，開工先重測當前建置。下表為建議目標。

| 項目 | 首測區間 | 如果超出 |
| --- | --- | --- |
| 開場同級普通怪 | 約 4–6 次有效普攻或 5–9 秒 | 先核對普攻間距、敵人硬直和接觸距離。 |
| 首隻教學幼狂豬 | 約 12–22 秒完成；通常至少出現一次可讀衝鋒 | 太快就保留讀招機會；太慢先縮冗長硬直或移動空窗。 |
| 同級精英 | 約 25–45 秒；至少兩次可利用的破綻 | 先看威脅、窗口和節奏；避免只靠增厚血量拉長。 |
| 普通敵人一次可避攻擊 | 約最大生命 8–14%；重招約 18–24% | 檢查連中或重疊傷害。新手在標準開局可捱到至少三次完整重招。 |
| 普通洞窟首領 | 單人約 90–150 秒；首領階段至少各有一次可反擊窗口 | 先調窗口長度、援軍與首領空跑時間；記錄不同職業的處理時長。 |
| 首次永久改招 | 從第一次接敵起 60–90 秒內見到；選後 15–30 秒有實戰機會 | 縮短往返路程或提示。 |
| 首次深化選擇 | 首節約第 25–40 分鐘；選後一場內有適合的測試情境 | 縮減前置要求；驗證單人和組隊路線耗時是否接近。 |

## 3. 角色強度預算

以 **100** 代表新角色對固定基準敵人的有效單體 DPS。整階段預算包括等級、當期普通裝備及改招總和。每個檢查點先用固定敵人，再用當期同級怪確認威脅仍有感。高稀有度配置另作壓力測試。若 MVP 與現行等級或裝備曲線有落差，先量來源和落差，只在試玩配置驗證新預算，再決定是否遷移正式角色。

| 檢查點 | 對固定敵人單體指數 | 同級遭遇要保留的壓力 |
| --- | --- | --- |
| 初始 | 100 | 一隻可打，兩面受敵時要先處理一邊。 |
| 首次改招 | 100–105 | 仍要讀精英出招。群體覆蓋開始比初始清楚。 |
| 首節結束 | 108–115 | 側翼或疊招仍會迫使走位；近程輸出窗口有價值。 |
| 首兩區打完 | 120–135 | 有第二配置，能針對地形換打法；同級精英仍有至少兩次可利用窗口。 |
| 第一章中後段 | 140–165 | 角色在舊區可見地變強。同級事件仍要求處理優先目標。 |
| 第一章首通前 | 170–200 | 舊區清得順。同級首領仍測讀招、分工及輸出窗口。 |
| 首輪終局配置完成 | 190–225 | 達成後新增挑戰優先靠變奏、配置取捨及協作。 |

- 一個常見永久改招本身以 **0–5% 同級單體收益**起步；真正適合的敵群情境可以有 **10–25% 清場時間改善**。比較時要包含不適合的場景，例如伴隨援軍的首領和純單體窗口。
- 成長曲線按里程碑看總和。裝備、暴擊、攻速、倍率和額外命中可互相放大；測試要包含常見組合、合理成裝和高端堆疊三種。
- 固定裝備的首次改招如果讓同級精英清場時間改善超過 **15%**，先查重複命中、次級觸發與冷卻。不要為了追平一個不平衡分支而替整區加血。
- 舊區強度感靠角色進展體現；公共守燈再限制高等級玩家對共享目標的瞬間輸出，讓新人有機會貢獻。

## 4. 首批招式和數值

倍率以下均以一次普通普攻傷害為 100%。數值由同一出招事件合併，整體仍受首測預算限制。

| 改招 | 首測規格 | 效用和限制 |
| --- | --- | --- |
| **遊俠 · 扇射** | 中箭 100%；兩支外箭各 30%；外箭各偏 16°。 | 同次出招同一目標只取最高一支；外箭命中別的目標才提升總輸出。 |
| **扇射 → 散羽** | 首個命中的外箭向另一目標分裂一次；追擊傷害 20%，尋敵半徑約 2.5 m。 | 每次出招最多一次分裂；避開該次出招已命中的目標。 |
| **扇射 → 回射** | 0.35 秒後沿原方向補射中心一箭，25% 傷害；每 5.5 秒最多一次。 | 可補打原目標。需預判目標停留；初版以實測同級單體長期增幅 0–5% 校正冷卻和倍率。 |
| **衛士 · 收尾震波** | 每 3 擊成功連段，尾擊多一圈 2.1 m 震波，傷害 30%。 | 尾擊已命中的目標不吃這圈額外傷害。保留直擊武器的價值。 |
| **收尾震波 → 雙環** | 0.35 秒後出外環，約 2.1–3.2 m，20% 傷害。 | 同次出招每隻敵人最多吃一圈。敵方危險圈有獨立形狀、線條和顯示優先級。 |
| **收尾震波 → 反擊** | 翻滾結束後 1.2 秒內首個有效普攻可放原震波；內置冷卻 5 秒。 | 與連段尾擊共用本次震波額度。可提早釋放，避免同一擊出兩圈。 |

以上六項先證明多一支箭、多一圈都有感。**中局再加放置型攻擊。** 原型用「落地火種」：普攻命中後，在落點留下可見標記，0.6 秒後爆開，半徑約 1.7 m、傷害 35%、每 6 秒最多一次。爆開最多命中三個目標，初版略過觸發它的主目標；適合沼澤分批進場與窄口。三發箭、兩個圈、火種各自解不同戰鬥問題。

實作預設次級效果不再觸發同類效果，不額外推進職業資源／連段；有特別規則才由招式定義明示。貼身同目標、寬距分散目標、窄路同時命中與高攻速觸發分開驗證。

## 5. 開局、中局、結尾和終局交付

| 階段 | 要給玩家的內容 | 可結束／可回來的位置 |
| --- | --- | --- |
| 首 10 分鐘 | 選角、初戰、第一次永久改招、前哨立即試招。 | 看見新招已裝備，任務卡留下附近下一個能做的目標。 |
| 首節約 30–45 分鐘 | 短前哨、公共守燈或單人路線、第一次深化、草原洞窟作完整驗收。 | 結算發放並記錄永久進展。洞窟段落、當前里程碑和野外目的地可恢復。 |
| 首兩區 | 草原練寬向覆蓋；森林練窄路、列陣和換位。森林給第二頁配置，讓舊打法仍可用。 | 可保留兩套打法，以後和朋友返草原時可換回。 |
| 章節中後段 | 沼澤驗證延遲落點；雪原驗證移動反擊；火岩驗證短輸出空檔和援軍。每區有短遭遇、公共活動、區域驗收。 | 每區完成主目標後有章節進度及下一站。常駐解鎖可循野外或副本路線完成。 |
| 古樹林章節結尾 | 鹿王三階段驗收讀招、側翼與收招輸出。單人縮減同時威脅，多人保留分工。 | 世界結果、招式成長和隊伍貢獻有一頁正式結算。可進下一章、挑戰進階內容或留在舊區。 |
| 終局 | 精通熟悉配置、完成另一條分支、進階公共及公會活動。挑戰優先改敵群、時間窗、地形和目標。 | 5–10 分鐘可做一個地區目標；較長隊伍活動有中途檢查點及清楚結算。 |

鹿王驗收初值為 **5–8 分鐘**；隊伍版本按參與人數調整援軍數和方向。每個階段都有近戰可用嘅出手機會、遠程需留意的移動壓力，至少兩種分支能穩定通過。開局節奏跑通後才量全章總長。

耐玩度先用三種可重組因素做內容：**敵人編組、場地、目標**。例如同一個森林前哨，第一輪打列陣，另一輪保護兩盞分開的燈；相同怪種仍會逼玩家改打法。已學招式因這些差異而有用途。事件輪替之外，角色重要解鎖都保留常駐途徑。裝備與工坊提供配置選擇；公共獎勵按完成貢獻、階段和唯一收據發放。

## 7. 試玩和擴展門檻

1. **手感原型**：兩職業各一個改招，輪流測原版與改招版。記錄擊殺時間、傷害來源、命中目標數、首次改招生效和玩家有冇換站位。先過單體預算，再驗證多目標收益。
2. **草原可玩切片**：新增永久成長、第一次深化、野外與洞窟進度和結算。驗收首次學招、重登入、跨區、配置切換、收據唯一與新舊存檔。
3. **公共事件及森林**：測單人、兩人、三人、高低等級共玩、遲加入和斷線重連。新人應能在事件中親手用到自己新學的招。森林驗收兩套配置各有用處。
4. **全章與終局**：看到真實跨節回訪、配置改用和共玩價值後，才逐區擴展。PvP 在 PvE 效果確認後，用獨立傷害、控制和觸發規則驗收。

真人首測用 **8 人兩節**，每節約 30–45 分鐘。暫定至少 6 人在選後兩次出手內能指出變化；至少 5 人能以操作證明新招改變了打法。第二節記錄玩家能否自行找回配置和進入下一個目標。回訪率、分支多樣性與重複活動疲勞，等較大批試玩用真實行為量度。自動化負責數值基線、狀態、出招和壓力測試，沿用現有自動試玩及版本識別。

每輪把「建置、測試條件、實際數值、保留／更新決定」記到本文件的修訂紀錄或連結戰報，逐次校正首測初值。現有參考：[開局規格](../FIRST_TEN_MINUTES_PLAN.md) · [既有平衡函式](../../src/progression.js) · [自動試玩流程](../LIVE_PLAYTEST.md)。

### 首輪實際記錄

建置 `9a5b53111f1a`，標準 Lv.1，Chrome 固定輸入、固定目標與傷害隨機值。衛士／遊俠實際初始最大生命為 92／67；第一次普攻間距均為 1.064 秒，點燈後幼狂豬最大生命為 67。這是固定條件結果，完整戰鬥耗時、長期單體 DPS、多目標清場秒數和真人理解度仍需試玩。

| 對照 | 原版 | 原型 |
| --- | --- | --- |
| 遊俠正面、左右三個分散目標 | 9 / 0 / 0 | 9 / 3 / 3 |
| 遊俠貼身正中單一目標 | 正中箭 9 | 9；只命中一次 |
| 衛士第三擊，正面及背側各一目標 | 22 / 0；原版已有一個前方震波 | 22 / 2；新增腳下震波只補打原攻擊未撞到的目標 |

扇射原型同一發箭組只結算一次同一目標，正中箭在同一更新幀先判定；側箭先接觸時會按側箭傷害結算。移動或交叉目標是否需要更嚴格嘅最高傷害優先，留待 Phase 1 試玩。腳下震波在擊中名單中排除原有普攻與原有前方震波的目標。次級效果不觸發裝備命中回復，也不把超出投射物上限的側箭轉成額外單體傷害。

在本機開 `/?growth=prototype`，選林風遊俠或守燈衛士，前往晨光草原。遊俠用地面普攻，衛士用持盾地面普攻第三擊。原版對照入口用 `/`。使用本機測試伺服器及新瀏覽器設定檔做比較，原型由網址啟用，永久選擇會在 Phase 2 接上。可用 `LV_GAME_URL=http://localhost:8080/ node tests/growth_prototype.cjs` 重跑固定對照。自動試玩清過開場波次及第二間房嘅波次，無頁面錯誤。

### 第二輪實際記錄

建置 `3b8fd0160e48`。在原本的本機 Phase 1 原型上加入固定的第二段改招。用 `/?growth=advanced` 試回射與雙環；`/?growth=prototype` 保留第一段；`/` 是原版。全部只限本機非正式建置，進晨光草原後才生效。

| 固定對照 | 第一段 | 第二段 |
| --- | --- | --- |
| 遊俠正面及兩側 | 9 / 3 / 3 | 11 / 3 / 3。正面多 2 點來自約 0.35 秒後的回射。 |
| 衛士正面、內側、外側 | 22 / 2 / 0 | 22 / 2 / 2。外側目標要等第二圈先中。 |

回射在原地沿原方向發出，約 5.5 秒最多一次。以固定 1.064 秒普攻間距及 9 基礎傷害估算，每六次普攻最多多 2 點，循環單體增幅約 **3.7%**。這是固定測值估算，真實站位、暴擊與裝備組合仍要另測。雙環在約 0.35 秒後命中 2.1–3.2 m 的外圈；已命中的敵人即使走入外圈也不會再被同一次改招結算。兩種待出手效果會在換區時清除。
