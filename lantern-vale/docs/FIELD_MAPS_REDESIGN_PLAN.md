## 一、v5 核心設計架構（基於 Path of Exile 2 終局圖集研究）

綜合 PoE 2 社群對終局地圖（*Savannah / Steppe / Sandspit / Burial Bog / Cenotes / Azak Bog / Crypt*）的結構與口碑分析，12 張常駐野外地圖刻意採 **「5 大拓撲類型黃金配比」**，讓玩家每換一張地圖都體驗到截然不同的空間節奏，並統一以 **A Short Hike 溫馨像素 3D 美術** 呈現：

| 拓撲類型 | 張數 | 對應地圖 | 設計目標與跑圖手感 |
| :--- | :--- | :--- | :--- |
| **① 大空曠原野型**<br>*(Savannah / Steppe / Blooming Field)* | **3 張** | **#01 晨光草原**<br>**#08 珊瑚潮汐灣**<br>**#12 🍁 紅楓工坊谷** | 大片不規則無隔牆開闊平原／淺海金沙灣／秋楓高原，僅點綴 `9–11` 處小型岩樹，專為騎馬奔馳、大範圍 AOE 割草與全屏元素連爆而生。 |
| **② 狹長流暢線性型**<br>*(Sandspit / Creek / Ravine)* | **3 張** | **#04 霜冬雪原**<br>**#10 🌸 櫻花水都**<br>**#11 🌀 蒼穹巨環谷** | 細長彎曲的單／雙向長條走廊（幾乎零回頭路）：450m 高山纜車大雪道、S 型落櫻錦鯉溪谷、新月穿環滑翔風洞，一路清怪直抵終點。 |
| **③ 寬敞大環形競技場**<br>*(Burial Bog)* | **2 張** | **#05 燼煙火岩區**<br>**#06 古樹林** | 寬敞流暢的外環（繞一圈即清完 80% 聚落，無拉桿拖節奏）＋中央獨立奇觀核（熔岩演武浮島／世界樹幹天橋），爽快不卡腳。 |
| **④ 開闊＋跳島／窄口混合型**<br>*(Cenotes)* | **2 張** | **#07 浮空遺跡群**<br>**#09 沉沒電光都** | 13 座高低海蝕柱＋多層飛瀑燈塔巨崖、以及斜 45° 淹水電車站＋彩柱條紋棚天台群，在開闊平台戰與氣流／滑索跳島間切換。 |
| **⑤ 高密度立體迷宮型**<br>*(Azak Bog / Crypt)* | **2 張** | **#02 低語森林**<br>**#03 霧潮沼澤** | 保留 2 張最具挑戰性的高密度迷宮（36 處巨根岩脊隔牆、14 座碎裂海怪觸手群礁與 7 座交錯木棧道），搭配 4 座藍光檢查點與單向滑翔徹底消除走回頭路痛點。 |
