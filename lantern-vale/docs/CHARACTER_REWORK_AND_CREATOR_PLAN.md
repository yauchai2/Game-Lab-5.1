### 3. ⚠️ 關鍵技術瓶頸與 WebGL 轉檔優化對策
檢驗發現原始 `SK_Adventurer.fbx` 的骨架包含 **253 根骨骼**（含大量 `_end` 末端假骨、十指細骨、未使用的 `Wing.*`/`Tail.*` 與 40+ 條裙襬輔助骨），若直接轉成單一 GLB 在瀏覽器跑多人同屏，會觸發 WebGL `MAX_VERTEX_UNIFORM_VECTORS` 風險並大幅拖慢 CPU 蒙皮運算。

**專為《燈谷行》設計的 3 層資產轉換管線（`scripts/build_character_assets.py`）**：
1. **網格與貼圖分離輕量化**：
   - 輸出 1 份統一模組本體 `game/assets/char/adventurer_base.glb`（36 組蒙皮網格＋精簡清理後的骨架，預估 `1.4–2.0 MB`），貼圖依重要度最佳化至 `256×256`（服飾／武器）與 `512×512`（臉部／眼睛保持絕對清晰，嚴守不壓糊原則）。
   - 5 套動畫**純骨架軌道輸出**（不含任何幾何體與貼圖）：`anim_fighter.glb`、`anim_archer.glb`、`anim_mage.glb`、`anim_necromancer.glb`、`anim_monk.glb`（每份僅約 `120–220 KB`，按需載入或進場預載）。
2. **材質統一轉為《燈谷行》暖木卡通著色（Pixel-Toon Alignment）**：
   - 載入 GLB 後自動將材質包裝為 `MeshToonMaterial`（搭配現有 3 階漸層 `gradientMap` 與暖色環境光），確保新角色不會像塑膠模型，而是完美融入 270p 暖木手繪世界！
3. **跨實體實例化（`SkeletonUtils.clone()`）與 VRAM 零洩漏**：
   - 玩家本人、角色選擇頁 5 英雄、城鎮 NPC 與 MMO 遠端玩家全部從已快取的 `adventurer_base.glb` 進行 `SkeletonUtils.clone()`，**共用幾何體與貼圖**，只複製骨架實例與切換顯示部位。

## 三、全新骨骼動畫狀態機（`src/char_anim.js`）

| 遊戲狀態 | 對應動作 Clip | 循環模式 | 特別手感細節 |
| :--- | :--- | :---: | :--- |
| 城鎮／野外待機 | `Idle` | Loop | 5 秒未戰鬥自動由 `CombatIdle` 平滑淡入放鬆待機 |
| 戰鬥警戒待機 | `CombatIdle` | Loop | 攻擊或施法後維持 5 秒戒備架勢 |
| 移動／疾步 | `Walk` / `Run` | Loop | 依實際速度動態調整 `timeScale`（0.85x–1.35x），搭配腳步塵土粒子 |
| 鎖定側移／後退 | `RunL` / `RunR` / `RunBack` | Loop | 邊瞄準邊移動時依移動與面朝夾角自動切換方向跑姿！ |
| 跳躍與滯空滑翔 | `Jump` → `Fall`/`Falling` | Once → Loop | 起跳播 `Jump`，下落／滑翔切 `Falling` 並展開滑翔星翼 |
| 普攻（站立／移動中） | `Attack` / `RunAttack` | Once | **移動中普攻改播 `RunAttack`**，動作流暢不滑步！ |
| 技能拼圖施法 | `SkillAttack` / `CastingLoop` | Once / Loop | 依主動寶石類型觸發重擊或持續施法姿勢 |
| 採集木／礦／魚 | `Gathering` | Loop | 按 `F` 進入採集小遊戲時播放真實採集動作！ |
| 翻滾／格擋減傷 | `BlockingLoop` / 翻滾位移 | Once | 守衛舉盾與翻滾附帶動態前傾與殘影 |

| 受擊與陣亡 | `GetHit` / `Death` | Once | `GetHit` 不中斷移動，陣亡時完整播完倒地動畫再轉場 |
